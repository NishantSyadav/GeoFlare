# GeoFlare 🔥🌍

### Harmonizing Earth's Burning Activity

GeoFlare is a NASA Space Apps Challenge project designed to analyze and harmonize active-fire hotspot observations from MODIS and VIIRS satellite products.

The platform aims to help users explore fire activity across selected regions and time periods through interactive maps, historical trends, burning activity calendars, anomaly indicators, and downloadable reports.

## 🎯 Project Objectives

- Explore MODIS and VIIRS active-fire observations.
- Standardize and process hotspot records.
- Analyze spatial and temporal fire activity.
- Investigate differences between satellite observations.
- Identify unusual changes against historical activity.
- Present results through an interactive web dashboard.

## 🛠️ Technology Stack

- Frontend: Vue 3, TypeScript, Vite
- Backend: Python, FastAPI
- Data processing: Pandas, NumPy
- Geospatial processing: GeoPandas, Shapely
- Visualization: Leaflet and charting libraries
- Version control: Git and GitHub

## 📁 Project Structure

- `frontend/` — Web dashboard
- `backend/` — REST APIs
- `data-pipeline/` — Data ingestion and cleaning
- `geospatial/` — Spatial processing and aggregation
- `harmonization/` — MODIS–VIIRS comparison and harmonization
- `analytics/` — Historical trends and anomaly detection
- `data/` — Dataset organization and sample data
- `docs/` — Architecture, data dictionary and API contracts
- `scripts/` — Pipeline and demonstration scripts
